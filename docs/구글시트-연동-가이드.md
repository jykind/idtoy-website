# 견적 문의 → 구글 시트 연동 가이드 (5분)

사이트의 견적 문의가 구글 시트에 자동 저장되고, lifeyes1002@gmail.com로 알림 메일이 오게 하는 설정입니다.

## 1. 구글 시트 만들기
1. [sheets.google.com](https://sheets.google.com) 접속 (lifeyes1002@gmail.com 로그인)
2. **빈 스프레드시트** 새로 만들기 → 이름을 `IDToys 견적문의`로 변경

## 2. 앱스스크립트 붙여넣기
1. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 클릭
2. 편집기에 기본으로 있는 코드를 **전부 지우고**, 이 폴더의 `google-apps-script.gs` 파일 내용을 **전체 복사해서 붙여넣기**
3. 💾 저장 (Ctrl+S)

## 3. 웹앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** 클릭
2. ⚙️(톱니) → 유형 선택에서 **웹 앱** 선택
3. 설정:
   - 설명: `견적폼` (아무거나)
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 중요!
4. **배포** 클릭
5. "액세스 승인" 창이 뜨면 → 계정 선택 → "안전하지 않은 페이지로 이동(고급)" → **허용**
   (내가 만든 스크립트라 안전합니다. 구글이 모든 개인 스크립트에 보여주는 표준 경고입니다)
6. 완성되면 **웹 앱 URL**이 나옵니다:
   `https://script.google.com/macros/s/긴문자열/exec`

## 4. URL을 Claude에게 전달
복사한 `/exec` URL을 채팅에 붙여넣어 주세요.
사이트에 연결하고 테스트 전송까지 확인해 드립니다.

---

### 참고
- 이후 문의가 올 때마다: 시트에 한 줄 추가 + 메일 알림 도착
- 스크립트 코드를 수정하면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다
- 알림 이메일 주소를 바꾸려면 코드 상단의 `NOTIFY_EMAIL`만 수정

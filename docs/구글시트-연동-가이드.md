# 견적 문의 → 구글 시트 연동 가이드 (v2)

문의가 접수되면 자동으로:
1. **구글 시트**에 한 줄 저장 (머리글 한국어/태국어 병기)
2. **고객에게** 접수 확인 메일 — 고객이 쓴 언어(한/영/태)로 자동 발송
3. **관리자(lifeyes1002@gmail.com)에게** 알림 메일 — 외국어 문의는 [한국어 자동 번역] 병기

## 처음 설치할 때
1. [sheets.google.com](https://sheets.google.com) 접속 (lifeyes1002@gmail.com 로그인)
2. 빈 스프레드시트 생성 → 이름 `IDToy 견적문의`
3. **확장 프로그램 → Apps Script** → 기본 코드 전부 삭제 → `google-apps-script.gs` 내용 전체 붙여넣기 → 저장
4. **배포 → 새 배포** → ⚙️ 유형 **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 중요!
5. 권한 승인 (고급 → 이동 → 허용)
6. 웹 앱 URL(`.../exec`)을 Claude에게 전달 → 사이트에 연결

## 코드를 수정(업데이트)할 때 — URL이 안 바뀌게!
1. Apps Script 편집기에서 코드 교체 → 저장
2. **배포 → 배포 관리 → ✏️(수정) → 버전: "새 버전" → 배포**
   - ⚠️ "새 배포"를 누르면 URL이 바뀌어 사이트 연결이 끊깁니다. 반드시 **배포 관리**에서!
3. 새 기능(번역·메일)이 추가된 버전은 **권한 승인 창이 다시 뜰 수 있습니다** → 허용
4. 머리글을 바꾼 경우: 시트를 완전히 비우면 다음 문의 때 새 머리글이 자동 생성됩니다

## 참고
- 알림 이메일 주소 변경: 코드 상단 `ADMIN_EMAIL` 수정
- 고객 확인 메일은 고객이 이 메일에 "회신"하면 관리자 지메일로 도착합니다 (replyTo 설정됨)
- Gmail 무료 계정은 하루 약 100통까지 자동 발송 가능 (문의 1건당 2통 사용)

# 도메인 구매 후 사이트 이전 가이드

> 현재 사이트: https://jykind.github.io/idtoy-website/ (GitHub Pages)
> 폼 백엔드: Google Apps Script (도메인과 무관 — **이전해도 수정 불필요**)

## 방법 A. GitHub Pages에 커스텀 도메인 연결 (추천 — 파일 이동 없음)

도메인만 사고 호스팅은 지금 그대로 쓰는 방법. **파일을 옮길 필요가 전혀 없습니다.**

1. 도메인 구매 (가비아, Cloudflare, 후이즈 등)
2. GitHub 저장소 `jykind/idtoy-website` → Settings → Pages → **Custom domain**에 도메인 입력
3. 도메인 업체의 DNS 설정에서:
   - `www.도메인.com` → CNAME 레코드 → `jykind.github.io`
   - 루트 도메인(`도메인.com`) → A 레코드 4개: `185.199.108.153` / `185.199.109.153` / `185.199.110.153` / `185.199.111.153`
4. GitHub Pages 설정에서 **Enforce HTTPS** 체크 (인증서 자동 발급, 몇 분~몇 시간 소요)
5. 아래 [공통: 주소 문자열 교체](#공통-주소-문자열-교체) 수행

## 방법 B. 다른 호스팅으로 완전 이전 (Cloudflare Pages, Netlify, 일반 웹호스팅 등)

### 옮겨야 하는 파일 (= 사이트 전부)

```
index.html          ← 홈
about.html          ← 회사소개
services.html       ← 제작 서비스
work.html           ← 제작 분야
collection.html     ← 쇼케이스
contact.html        ← 견적 문의 (폼)
privacy.html        ← 개인정보처리방침
404.html            ← 없는 페이지 안내
robots.txt          ← 검색엔진 설정
sitemap.xml         ← 검색엔진 사이트맵
assets/             ← 폴더 통째로 (css / js / icons)
id-toy-final-12/    ← 폴더 통째로 — 단, .jpg 와 .mp4 만!
```

- `id-toy-final-12/` 안의 **`.png` 원본은 올리지 마세요** (용량만 큼 — 사이트는 전부 .jpg를 사용)
- **폴더 구조를 그대로 유지**해야 합니다 (HTML이 상대 경로로 참조)

### 옮기면 안 되는 것

```
company-photos/     ← 개인 사진 포함. 절대 업로드 금지
docs/               ← 내부 가이드 문서 (Apps Script 코드 백업 포함)
.git / .gitignore / .claude / *.bat  ← 개발용
```

가장 쉬운 방법: GitHub 저장소가 곧 배포본이므로, 저장소를 ZIP으로 받아 그대로 업로드하면 됩니다
(저장소에는 위의 "옮기면 안 되는 것"이 애초에 없음 — .gitignore로 제외되어 있음).

## 공통: 주소 문자열 교체

도메인이 바뀌면 파일 안에 박혀 있는 옛 주소를 새 주소로 바꿔야 합니다.
**모든 파일에서 `https://jykind.github.io/idtoy-website` → `https://새도메인.com` 일괄 치환** (Claude에게 "도메인을 ○○로 바꿨어, 주소 교체해줘"라고 하면 처리)

바뀌는 위치:
| 파일 | 항목 |
|---|---|
| 모든 `*.html` | `<link rel="canonical">`, `og:url`, `og:image` |
| `sitemap.xml` | 각 페이지 URL |
| `robots.txt` | `Sitemap:` 줄 |

## 바꿀 필요 없는 것

- **Google Apps Script 폼 연동** — `assets/js/site.js`의 QUOTE_ENDPOINT는 구글 서버 주소라 도메인과 무관
- 구글 시트, 메일 발송 — 그대로 동작
- 언어 전환(KO/EN/TH) — 그대로 동작
